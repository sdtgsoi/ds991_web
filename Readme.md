# Development

`ds991.html` is the **single source of truth**. Edit only that file; there is no
build step.

`index.html` is a byte-identical copy that exists purely because GitHub Pages
serves `index.html` from the repository root. Regenerate it before committing or
pushing:

```bash
./sync.sh            # ds991.html -> index.html, with validation
./sync.sh --check    # report whether the two files agree (exit 1 if not)
```

The script refuses to copy a page that is empty, is missing its main elements, or
has a JavaScript syntax error, so a half-saved file can never reach the
published copy.

## Code map

The page is one IIFE, ordered bottom-up so helpers exist before use. Each region
is introduced by a `/* ==== SECTION ==== */` banner with a short explanation:

| region | what lives there |
|---|---|
| header comment | architecture + the **cursor model** (read this first) |
| STATE | `S`, `root`, `stack`, token factories |
| KEY LAYOUT / BUILD KEYPAD | the keyboard as data, and turning it into buttons |
| DISPLAY HELPERS | expression tree → LCD HTML, caret and slot boxes |
| NUMBER FORMAT | NORM/FIX/SCI, engineering, exact fractions |
| EDITING | caret model, movement (`doLeft/doRight/doField`), deletion, `input*()` |
| EVALUATOR | tree → value; real and complex share one path |
| MENUS / SETTINGS / MODES | menu state machine and the calculation modes |
| BASE-N / MATRIX / VECTOR / STATISTICS | the mode-specific maths |
| RENDER | one draw function per screen |
| CLEAR / ANS | `=` , STO, CALC and numerical SOLVE |
| MODE KEY HANDLERS | editing the cell grids of the non-expression modes |
| DISPATCH | the single entry point for every key press |
| OPTN ACTIONS / PHYSICAL KEYBOARD / INIT | option menus, real keyboard, boot |

The `pos` of a cursor frame is a **digit offset**, not a token index — a token
such as `"12"` spans two caret positions. That is what makes LEFT/RIGHT move one
digit and UP/DOWN line the numerator up with the denominator.

Keyboard shortcuts use the same dispatcher as the on-screen keys; notably `/`
inserts a **fraction** template (not a division sign).

Regression suites (no dependencies, plain Node) — see `tools/README.md`:

```bash
node tools/run_tests.js      # run everything
```

`tools/shot.sh out.png "2 ADD 3"` renders the page with headless Chrome and
replays a key sequence first (`?keys=`), which is handy for checking layout.
`node tools/computed.js <selector>` prints an element's computed style, which is
how CSS cascade/specificity problems get diagnosed.
