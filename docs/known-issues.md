# 已知限制与兼容性

更新于 2026-10-26。功能状态与证据见本文、[菜单审计](menu-audit.md) 和 [测试文档](testing.md)。

## 数值行为

- 所有数学计算使用 JavaScript Number（双精度浮点）。约 10 位显示精度不等于所有输入都达到 10 位计算准确度。
- 分数显示通过浮点数逼近有理数；不保留精确分数、根式或符号表达式。
- 多项式支持有效次数 1–4。二次根使用稳定公式；三四次根是迭代近似，残差/系数验证失败返回 Math ERROR。高次重根、近重根、极端尺度仍可能不准确或无法求解；残差检查不保证病态问题的前向误差。
- 不等式按数值实根分段，使用近似阈值分类/合并根。近重根、小间距根和退化成常数的表达式仍需扩展验收；不是符号不等式求解器。
- 积分固定使用 400 段复合 Simpson 法；导数使用中心差分；SOLVE 使用有限次牛顿迭代及区间回退。奇点、不连续、高振荡和不良初值没有通用精度保证。
- 阶乘限制到 170，排列组合直接使用中间阶乘。某些最终结果可表示的大参数仍可能失败。
- 复数域、运算溢出、退化统计、零向量夹角、近奇异矩阵、BASE-N 位宽等边界尚未全面验证。

## 功能缺口

- 两种数学输入/输出设置生效；LINE 渲染尚未实现，菜单已明确禁用。
- Fix/Sci 位数及 Norm 1/2 已可配置；工程符号、Freq、小数点/分隔符和多行字体仍未实现。
- 中英菜单已支持，模式提示/错误/键标记仍未全部翻译；刷新后保留变量/设置/历史、完整模式专属 OPTN 仍未完成。
- 物理键盘使用 `event.key`，非美式布局按其实际字符输入；没有物理位置映射。Shift 单独不激活计算器 SHIFT，请用 `s`。IME composition 期间不接受快捷键。

## 浏览器与工具

- 本次使用本机 Chrome 在 390 和 1280 CSS 像素宽度做冒烟检查；没有把它等同于 Android/iOS 真机触摸测试。
- Safari、Firefox、移动浏览器、深层幂布局、缩放及屏幕阅读器未完成完整验收。
- 开发工具要求 Node.js 22+ 与 Chrome/Chromium。可用 `CHROME_PATH` 指定可执行文件。启动无头浏览器需要进程权限与 localhost 监听权限。
- 工具只监听 127.0.0.1，使用临时浏览器配置和随机端口，结束后清理。每次运行创建自己的浏览器与服务。

## 文档来源

说明书和直接引用材料可保存在本地 `991-docs/`，该目录不纳入 Git。[CN X 官方 V02](https://www.casio.com/content/dam/casio/global/support/manuals/calculators/pdf/004-zh-cn/f/fx-991CN_X_B_CN.pdf) 是目标型号依据；EX 英文资料用于通用功能交叉核对，不能视为 CN X 全部功能的验收标准。`temp-docs` 是指数设计历史，`q-tests` 是人工测试草案；规范、计划和历史资料均不能证明实机验收通过。

文档核对新增的明确差异：真机没有 Z，变量 M 与独立存储器 M 是同一值；复数 i/∠ 真机入口为 ENG/SHIFT ENG，网页仍使用 ALPHA ENG/SHIFT RPAREN。Pol/Rec、÷R、Rnd、随机等部分面板标记尚未接入相应动作，本次文档更新没有修改这些代码行为。
