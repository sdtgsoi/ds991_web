### 浏览器测试退出清理

GitHub Actions 的 Chrome 冒烟测试在删除临时配置时遇到 `ENOTEMPTY`。浏览器工具现在先请求 Chrome 正常退出，必要时发送终止和强制终止信号并等待进程关闭；删除目录对短暂占用进行有限重试，永久失败仍报错。新增生命周期专项和浏览器动作失败路径检查，并纳入 CI。日志只能确认清理失败，尚不能证明哪个 Chrome 进程造成目录非空；修复后的 Linux Actions 已通过，见 [测试记录](testing.md)。
