# 菜单与实机手册对照、修复记录

检查日期：2026-10-26。目标型号为 **fx-991CN X**，不是 fx-991EX，也不是 CW 系列。本次依据手册和浏览器复现检查，没有实体机器的逐像素/逐按键验收。

## 参考资料与型号边界

1. CASIO《fx-991CN X 用户说明书》，编号 **RJA530830-001V01**，[原版 PDF 镜像](https://manuals.plus/m/9c6b41d1f8e83c52eb602fd18a154beda8144dbb748a12661712ebc2dcaac12c.pdf)。这是卡西欧原始文档的镜像，不采用镜像站自动生成的产品摘要作为依据。原官方旧下载地址本次不可访问。
2. 用户提供的本地 `991-docs/manual casio fx-570_991EX_EN.pdf`，编号 **RJA532432-001V01**，46 页；用于核对通用菜单导航、设置和分类表。对应 [CASIO 官方 EX PDF](https://www.casio.com/content/dam/casio/global/support/manuals/calculators/pdf/004-en/f/fx-570_991EX_EN.pdf)。
3. [NIST CODATA 2010 原始常数表](https://physics.nist.gov/cuu/Constants/ArchiveASCII/allascii_2010.txt)，核对科学常数的数值版本。
4. [NIST SP811 单位换算表](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b8)，核对换算系数；包括 15°C 卡路里。

以下页码按手册印刷页码。CN X PDF 的相关内容位于 PDF 第 9–14、58–59、69–70 页；EX 内容见印刷页 4–8、37、44。

后续已找到并下载 [CASIO 官方 CN X V02](../991-docs/fx-991CN_X_CN.pdf)。上文保留初次审计的 V01 页码；复数专项使用 V02 pp.33–34，两版的部分页码不同。原件、EX 手册/指南、引用图片和数据表统一见 [引用材料目录](../991-docs/reference-materials.md)。

**型号差异：CN X 是 10 个主模式；EX 是 12 个。** 目前主模式集合及顺序符合 CN X：计算、复数、基数、矩阵、向量、统计、表格、方程/函数、不等式、比例。EX 的分布和电子表格不列为本项目缺失项。CN X 的语言设置应保留；EX 的 QR/电子表格相关选项不直接移植。

## 对照结论与本次处理

| 范围 | 原有偏差 | 本次状态 |
|---|---|---|
| 通用导航（CN X p.8） | 文字菜单无编号；两栏排版与按键索引不一致；没有父菜单；SHIFT 会移动选择 | 已改为明确编号、分页、LEFT 返回父菜单、AC 关闭；SHIFT 不再充当导航 |
| 触摸与确认 | 仅主图标有点击事件，文字项目不能点；OK 对菜单无效 | 所有菜单项目支持 pointer 选择和键盘激活，`=`/OK 可确认 |
| 主菜单标题 | 始终使用当前模式名，移动选择时标题不对应 | 标题随选中模式更新；图标与布局仍是模拟风格 |
| 设置（pp.11–13） | 仅 6 项并循环切换，混入复位/退出 | 按 CN X 顺序建立 14 项、四页；有子选项和返回路径 |
| 输入/输出（pp.9–11） | MATH/LINE 只改标签 | 数学输入的数学/小数输出两项生效；两项 LINE 选择明确标为未实现 |
| 角度单位（p.11） | 每按一次循环单位 | 三项显式选择，应用后关闭菜单 |
| 显示格式（p.12） | FIX 固定 2 位、SCI 固定 6 位，Norm 没有 1/2 | Fix 0–9、Sci 0–9（0 表示 10 位）、Norm 1/2；Sci 保留有效位末尾零，Norm 阈值分别为 10⁻² / 10⁻⁹ |
| 分数结果（p.12） | 错用“显示分数开/关” | 改为带分数/假分数；与小数输出选择分离 |
| 复数、方程和数表设置（pp.12–13） | 缺少相关设置 | 支持直角/极坐标显示、复根输出开关、f-only / f+g；复根输出是数值过滤，未承诺与实机全部解显示流程一致 |
| 语言和对比度（p.13） | 没有菜单选项 | 中英菜单切换、屏幕对比度调整；语言覆盖菜单，其他屏幕信息尚未全部翻译；对比度使用 CSS 近似 |
| 复位（pp.3、13） | 选择后立即执行，没有确认 | 三项保留，先进入确认画面；AC 取消；设置/全部复位保留语言和对比度；全部复位回到计算模式 |
| 科学常数（pp.57–58、68） | 12 项扁平列表，数值混用现代版本且以普通数字插入 | 补齐 6 类 47 项，按参考单顺序和快捷键；数值使用 CODATA 2010，表达式保留常数符号，元素电荷与 Euler e 区分 |
| 单位换算（pp.58、68–69） | 12 项扁平列表，温度插入空函数；复合表达式和答案后换算出错 | 补齐 9 类 40 命令，插入后缀换算节点；支持温度偏移、复合式优先级和答案续算；基数模式不开放 |
| 方程入口（p.45） | 必须先按 OPTN 才有类型选择，且允许一次方程 | 进入模式直接选择联立/多项式，再选择 2–4 元/次；保留 OPTN 重选入口 |
| 不等式入口（pp.54–55） | 次数和比较关系混在 OPTN 列表 | 新增进入时的次数→比较关系两级菜单；原 OPTN 仍是兼容的简化重选工具 |
| 比例入口（pp.56–57） | 固定第四项未知 | 先选第三项或第四项未知的两种形式 |
| 统计入口（p.37） | 仅“1变量/2变量”，未说明回归类别 | 按手册显示 8 种类型；仅单变量和线性回归可用，其余标为未实现 |
| 计算模式 OPTN（pp.22、27） | 原先误列 Abs、积分、求和等九项 | 已改为双曲函数、角度附加符、工程符号三类及完整子菜单；详见 [专项说明](calculate-optn.md) |
| 复数模式 OPTN（V02 pp.33–34） | Abs 占了第 1 项，实/虚部错页，缺少输出格式命令 | 已改为四函数首页、两命令次页，并实现只覆盖本次结果的输出转换；详见 [复数专项](complex-optn.md) |
| 不完整 OPTN 动作 | 部分可选项会插入求值器不支持的函数；退出数表不生效 | 计算菜单已移除误列的 Pol/Rec、FACT；BASE 二元位运算仍标为不可用；修复退出数表和清空统计数据后光标/缓冲区复位 |
| 数字表格中的全局菜单 | SHIFT+7/8/9 被数字输入吞掉 | 全局菜单快捷键提前分发；已进入编辑的单元格支持常数和标量换算 |

`*` 标记的项目点击后会显示尚未实现提示，状态不会被假切换。科学常数菜单的数字、ALPHA+A…F/M 和 SHIFT+= 快捷键按参考单对应；表达式键盘仍使用 README 中的网页快捷键映射。

## 当前菜单结构

```text
MENU → CN X 的 10 个模式
复数 OPTN → 辐角 / 共轭 / 实部提取 / 虚部提取
           ↓ → ▶r∠θ / ▶a+bi
SHIFT+MENU → 设置（每页 4 项）
  输入/输出 → 数学/数学、数学/小数；两种 LINE 尚未实现
  角度单位 → DEG / RAD / GRA
  显示格式 → Fix → 0…9
             Sci → 0…9（0 = 10 位）
             Norm → 1 / 2
  工程符号 *
  分数结果 → 带分数 / 假分数
  复数 → a+bi / r∠θ
  统计 Freq *
  方程/函数 → 复根开 / 关
  表格 → f / f+g
  小数点 *、数字分隔符 *、多行字体 *
  语言 → English / 中文
  对比度 → LEFT / RIGHT；AC 退出
SHIFT+7 → 6 类 → 47 个科学常数
SHIFT+8 → 9 类 → 40 个换算命令
SHIFT+9 → 设置数据 / 存储器 / 全部初始化 → 确认
```

## 可重现操作

以下为 `window.__calc.dispatch` 的键 ID，不是字符输入文本：

| 目标 | 键序列 |
|---|---|
| 角度改为弧度 | `SHIFT MENU 2 2` |
| Fix 3 | `SHIFT MENU 3 1 3` |
| Norm 2 | `SHIFT MENU 3 3 2` |
| 显示带分数 | `SHIFT MENU DOWN 1 1` |
| 切换中文菜单 | `SHIFT MENU DOWN DOWN DOWN 1 2` |
| 真空光速 | `SHIFT 7 1 3 EQUALS` |
| 5 cm 转英寸 | `5 SHIFT 8 1 2 EQUALS` |
| 32°F 转 °C | `3 2 SHIFT 8 DOWN DOWN 1 1 EQUALS` |
| 求二次方程 | `MENU 8 2 2` 后输入系数 |
| 二次 ≤ 0 不等式 | `MENU 9 1 4` 后输入系数 |
| 第三项未知比例 | `MENU 0 1` 后输入已知三项 |
| 取消复位 | `SHIFT 9 3 AC` |

菜单数字按**当前页**编号。旧脚本中用 `OPTN 5/6/7` 选择隐藏项的操作要改成翻页后 `1/2/3`。主菜单的 `0` 是网页保留的比例快捷入口，不是声称与手册图标快捷操作完全一致。

## 尚未完成的实机差异

- LINE 输入/输出、工程符号自动显示、统计 Freq、小数点/数字分隔符、多行字体仍不可用。
- 统计的非线性回归、概率相关命令、结果/数据/类型之间的完整 OPTN 树尚未实现。
- 矩阵仍使用自动选择空寄存器和方阵定义，缺少实机的寄存器选择、独立行/列维度、编辑/MatAns/Identity 等完整流程；向量也缺少完整选择/编辑流程。
- 计算模式三类入口与复数模式两页 OPTN 已修复，分别见 [计算专项](calculate-optn.md)、[复数专项](complex-optn.md)。BASE 的 OPTN 仍简化；双参数坐标运算和二元位运算等仍需求值器配合。
- 不等式 OPTN 重选、系数/结果页面、根的逐个显示、数表区间和 AC 行为，仍未全部对齐实机。
- 全局菜单在矩阵/向量维度选择拦截器中仍有限制；普通单元格可插入常数/标量换算，不能视为支持实机的全部单元格表达式语法。
- 常数采用 NIST 表中可获得的有效位；换算浮点系数及 parsec 的有限有效位未逐位比对硬件内部值。菜单字形、反色、图标和滚动标记为网页近似。
- 语言覆盖菜单，错误消息、按键标记和各模式提示还没有完整本地化。
